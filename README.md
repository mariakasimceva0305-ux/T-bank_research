# Память и выбор действий Transformer

Контролируемое исследование выбора памяти: когда полезнее искать прошлый опыт по его влиянию на следующее действие, а не по сходству текстового описания.

## Постановка

Синтетический поток разделяет поверхностное сходство ситуации и скрытое правило выбора действия. Связь между ними регулируется параметром rho. В каждом окружении соответствие правил действиям меняется, поэтому агенту нужен прошлый опыт.

Reader — decoder-only Transformer с 1,45 млн параметров. В каждом сравнении его веса фиксированы; меняется политика retrieval. Сравниваются отсутствие памяти, recency, cosine similarity, фильтрация успешных записей, MMR, оценки влияния на распределение действий и oracle по скрытому правилу.

## Результаты

Три независимо обученных reader, пять seed окружения; поток 400 шагов, память 128 записей, k=4. Оценивается точность действий на второй половине потока и sufficient@k — доля шагов с подходящей успешной записью в найденной памяти.

При rho=0 правило influence + floor даёт accuracy 0,249 / 0,676 / 0,135 на трёх reader; similarity — 0,148 / 0,145 / 0,138. Преимущество поиска по влиянию зависит от обученного reader и не воспроизводится на всех трёх моделях. Высокая доля подходящих записей сама по себе не гарантирует правильного действия.

## Запуск

```bash
pip install -r requirements.txt
python -m dam.train --steps 5000 --seed 0
python -m scripts.probe_embeddings
python -m scripts.probe_reader
python -m scripts.run_experiments --seeds 5 --steps 400 --capacity 128
python -m scripts.analyze --reader-seed 0
python -m pytest -q
```

Для нескольких reader повторите обучение с разными seed и передайте каждому запуску `--checkpoint` и `--reader_seed`; полный пример — в отчёте. `python -m scripts.replicate_checkpoints` проверяет сохранённые модели. Проверка 10.10.2026 воспроизвела шесть сохранённых accuracy; результаты — `results/replication_2026_10_10/replication.json`.

Выводы относятся к данной синтетической постановке и закрытому набору действий. Перенос на реальные диалоги требует отдельного эксперимента.
